HTTP/1.1 contract page

This page is meant to be SERVED over HTTP (the loopback server in tests/VisualDiff serves the whole html-websites tree). The 1999 engine profiles speak HTTP/1.1 on the wire:

  • Request line GET /… HTTP/1.1 (1996 profiles keep HTTP/1.0)
  • Mandatory Host: header — always present
  • Connection: keep-alive with per-origin socket pooling
  • Chunked transfer responses decode transparently
  • ETag / If-None-Match / If-Modified-Since revalidation with 304 served from cache
  • image/png advertised in Accept (the 1999 personas)
  • Charset: HTTP Content-Type charset beats the <meta> tag
  • Refresh header (this page carries Refresh: 30 when served with the test header injection)
