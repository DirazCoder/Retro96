Box Model Edge Cases

1. margin: auto centring

Centred the long way: width 400px with margin-left:auto and margin-right:auto. The tan box must sit dead centre of the 700px grey stage -- 150px of grey on EACH side. Nothing may tilt.

Centred the shorthand way: width 300px, margin: 0 auto 0 auto. The blue box must also be dead centre: 200px of grey on each side. If either box hugs the left edge, "auto" is being treated as zero.

2. Collapsing margins between adjacent blocks

The white gap between the yellow block and the pink block below must be exactly 40px -- the larger of their two 40px margins -- and NOT 80px. If the gap is 80px, margins are being added instead of collapsed.

Block A -- margin-bottom: 40px (yellow).
Block B -- margin-top: 40px (pink). Gap above must be 40px.

Now yellow (40px bottom) against green with only a 20px top margin: the gap must still be 40px (the maximum of the two), not 60px.

Block A again -- margin-bottom: 40px.
Block B2 -- margin-top: 20px (green). Gap above must be 40px.

3. Margin collapse through an empty block

Between the lavender block and the pale-cyan block sits an EMPTY block carrying 30px margins top and bottom. The margins must collapse straight through it: the total white gap between the two coloured blocks must be 30px, not 90px. The dotted red outline of the empty block may be visible INSIDE that gap or collapsed to nothing -- but the gap may not triple.

Upper block -- margin-bottom: 30px (lavender).
Lower block -- margin-top: 30px (pale cyan). The gap above must measure 30px in total.

4. Negative margins

A 500px anchor block offset 60px from the left edge of the grey stage. The green block below is pulled LEFT by a -80px margin and must poke out past the stage's left border, overlapping the page background. The gold block after it is dragged UP by -45px and must OVERLAP the tail of the green block instead of stacking below it.
Negative margin-left: -80px (green). I must bleed out of the left edge of the grey stage.
Negative margin-top: -45px (gold). I must overlap the green block above me; we are not friends.

5. Padding on an inline element

This sentence contains an inline element with padding: this bold run has 12px vertical and 16px horizontal padding and the sentence continues after it. The pink background must extend 12px above and below the text and 16px left and right of the bold words, wrapping with the line -- the padding must NOT push the surrounding words onto different baselines in a sane engine, but it must be VISIBLE.

6. Border on a table cell

header cell, 3px inset another header
Cell with a 4px solid red CSS border. The table itself has BORDER=0, so every visible line here comes from CSS on the TD. Cell with a 6px double blue border set through the three longhands: border-width, border-style, border-color.
Cell with a 2px dashed green border. No CSS border at all -- for contrast, this cell must be clean.

7. width: 100% inside a padded container

This block is width:100% INSIDE a 500px container with 30px padding and a 2px border. I must fill the container's CONTENT width exactly (436px) -- flush against the inner edge of the yellow padding on BOTH sides. If my dashed border crosses the yellow padding or pokes out past the brown frame on the right, width:100% is being resolved against the wrong box.

8. overflow (must not crash)

Not really a 1996 property, but the engine has to survive it. Each box below is 70px tall and holds far more text than fits. No crash, no infinite layout, no zero-size box:

overflow: hidden -- the text below this line is cut off stone dead at the 70px mark, with no scrollbar and no bleeding pixels past the border. Line two. Line three. Line four. Line five. Line six. Line seven. Line eight. Line nine. Line ten, well past the clip.

overflow: scroll -- scrollbars appear (or the content is simply clipped on a limited engine), and the box never grows past 70px tall. Line two. Line three. Line four. Line five. Line six. Line seven. Line eight. Line nine. Line ten, well past the clip.

overflow: auto -- same discipline as scroll but the engine decides whether bars are needed. Line two. Line three. Line four. Line five. Line six. Line seven. Line eight. Line nine. Line ten, well past the clip.
