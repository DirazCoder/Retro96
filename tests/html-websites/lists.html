[LI-09] Definition List

World Wide Web
A distributed hypertext information system in which documents are linked together by uniform resource locators, served over the network by hypertext transfer protocol daemons, and rendered by browser applications such as the one currently under test; this definition is intentionally long enough to wrap across several lines so the hanging indent of the description can be compared against the term above it, because a definition description that wraps flush with its term is a classic layout bug.
GIF
Graphics Interchange Format, an eight-bit indexed image format introduced by CompuServe in 1987, supporting one transparent palette index and multi-frame animation.
Tag Soup
HTML that violates every rule of nesting while still somehow rendering.
