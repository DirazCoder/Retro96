Retro96 → 1999 QA Suite

One page per checklist section of the 1996→1999 upgrade, plus the error-recovery, Acid1 and Y2K pages the test plan calls for. Load each page in the browser and read the in-page report lines; the xUnit suite (tests/RetroTests/Retro99SuiteTests.cs) asserts the same contracts headlessly.

  • Forms 4.01 — §5: label, fieldset/legend, button, optgroup, disabled/readonly, file, image, wrap
  • Tables — §6: row groups, frame/rules, bordercolor family, collapse/fixed CSS2 tables
  • Frames, iframe, object — §7: frameset battery (nav/banner/main children)
