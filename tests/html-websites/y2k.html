Y2K battery

The 1999→2000 rollover broke browsers that stored years as two digits. This page exercises every date surface that mattered:

  • new Date(2000, 0, 1).getYear() must return 100 (ECMA semantics: year − 1900, JavaScript 1.3 / JScript 5)
  • getFullYear() must return 2000
  • new Date(99, 0, 1).getFullYear() must return 1999
  • cookie expires dates past 2000 must store and survive
  • two-digit cookie years: 49 must read as 2049 (stored), 99 as 1999 (expired); http(s) only
  • Date.parse of 4-digit-year strings must land in the right epoch
