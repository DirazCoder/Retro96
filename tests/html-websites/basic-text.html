Long Paragraphs At Full Width

This is the first deliberately long paragraph. It exists so that the layout engine must break it into several lines at the full eight hundred pixel page width. In nineteen ninety-six, webmasters wrote paragraphs exactly like this one: long, winding, generously punctuated, and stuffed with words of wildly different lengths such as antidisestablishmentarianism and cat. The quick brown fox jumps over the lazy dog while five boxing wizards jump quickly. A hyphenated-word or two, some ALL-CAPS SHOUTING, digits 0123456789, and trailing punctuation!"? all belong in a proper wrap test, because line breaking must happen between words and not inside them, and the punctuation must stay glued to the word it follows.

Second paragraph, shorter but still wide enough to wrap two or three times: the markup for this paragraph contains no inline elements at all, so every line must be set in the same font, the same size, and the same color, and left aligned by default. Extra spaces between some words must collapse to single spaces under the normal HTML whitespace rules.

Wrapping Inside A Blockquote

Here is a paragraph set inside a blockquote, so its available width is reduced by the indentation on both sides. Wrapping must therefore happen earlier than in the outer paragraphs. The text is intentionally long enough to require at least three lines even at the reduced width, and it mixes short words with considerablylongerunbreakablewords to stress the line breaker.
And a second level of blockquote nesting narrows the measure further still; this text must wrap even sooner and indent another step on both margins, which is exactly how Netscape rendered nested quotations in the middle of the nineties.

Physical And Logical Inline Elements

Physical markup: bold text, italic text, underlined text, strike-through text, typewriter teletype text, big text, small text, superscripts x2 + y2 = r2, and subscripts H2O and aij + bkl.

Logical markup: emphasized text, strongly emphasized text, a code fragment (x = x + 1), sample output text, keyboard input, a variable name, a citation of a book title, and a definition of a term.

Combinations: bold italic, bold underline, red bold, small italic, double big, double small, bold code, and sup inside big: Vbig.

The Font Element

Absolute size ladder: size1 size2 size3 (base) size4 size5 size6 size7

Unquoted size attributes: size7 unquoted and size1 unquoted.

Relative sizes from base 3: minus2 minus1 plain base plus1 plus2 plus4 clamps to 7 minus5 clamps to 1

Colors: hex red, named blue, hex green, named darkred, short hex #ABC (browser-specific).

Faces: courier-ish face, arial-ish face, georgia-first fallback, bogus font falls back.

Combined attributes: size six purple times and unquoted size five teal courier.
