Whitespace and Inline Flow

Ordinary spaces between words should collapse to normal HTML spacing.

NBSP contrast: start[     ]end

Ten NBSP: start[          ]end

Adjacent inline tags: bolditalicunderlinered with no source whitespace between the tags.

Wrapped inline content: this long bold phrase should wrap naturally while the italic phrase continues and normal text follows.

Trailing and leading spaces around inline elements should follow HTML collapsing rules, not create large gaps.
