3. Floats: align=left and align=right

This teal square floats to the left and all of this text must flow down its right-hand side, wrapping around it like water around a stone. When the text passes the bottom of the float the lines stretch back out to the full width of the page. If the text overlaps the image, or the image refuses to let any text beside it at all, the float code has failed. Keep reading: the wrap should continue for at least three lines of body text so the shape of the remaining text is obvious even at a glance. This is line filler in the finest 1996 tradition. Almost there now. One more line to be sure the wrap ends.
And this orange square floats to the RIGHT, so the same paragraph test runs mirrored: the text must flow down the left side of the float. Wrapping bugs frequently favour one side only, which is why both directions are exercised. The text should hug the float edge without overlapping a single pixel, and should return to the full page width once past the bottom of the image. Fill fill fill, says the webmaster, padding out lines so the wrap is unmistakable.
